# Simon Mini-Game

The **Simon Mini-Game** is a simple yet engaging clone of the classic Simon game, which tests your memory and concentration. This project was created as part of a challenge provided by instructor Angila Yu.

In this game, you must remember and repeat a growing sequence of colors that the game displays. As you successfully repeat the sequence, the game level increases, making it more challenging. If you fail to replicate the pattern, the game ends.

## How to Play

1. **Start the Game:**
   - Press any key or start button to start the game.
   
2. **Follow the Sequence:**
   - The game will display a color (e.g., blue). You must click on the color it displayed.
   
3. **Repeat the Sequence:**
   - The game will add another color to the sequence. You need to repeat the sequence from the previous steps by clicking the colors in the correct order.
   
4. **Level Up:**
   - The sequence grows longer with each level. Repeat the pattern to level up. If you successfully repeat the sequence, the game continues to the next round.
   
5. **Game Over:**
   - If you fail to repeat the pattern correctly, the game ends.

## Key Features

- **Simple Gameplay:** The game uses basic color bubbles that you must click in sequence.
- **Increasing Difficulty:** As you progress, the sequence becomes longer, testing your memory and focus.
- **User-Friendly Interface:** The game is easy to play with clear instructions and intuitive color patterns.
